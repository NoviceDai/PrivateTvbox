## 重要：git SSH 推送代理配置错误（2026-07-18）
- 症状：SSH 推送 github 报 `Connection closed by UNKNOWN port 65535`，无法读取远程仓库。
- 根因：10808 端口实际是 **HTTP 代理**（curl `-x http://127.0.0.1:10808` 返回200；`--socks5` 失败）。但 `~/.ssh/config` 写的是 `ProxyCommand connect -S 127.0.0.1:10808`（`-S`=SOCKS 模式），对 HTTP 代理做 SOCKS 握手失败。
- git 全局 `http.proxy`/`https.proxy` 均为 `http://127.0.0.1:10808`（HTTP 代理，正确，HTTPS 推送可用）。
- 临时解决（不改配置）：`GIT_SSH_COMMAND="ssh -o ProxyCommand='connect -H 127.0.0.1:10808 %h %p'" git push origin main`（`-H`=HTTP CONNECT 模式）推送成功。
- 永久修复：把 `~/.ssh/config` 中 `connect -S` 改为 `connect -H`。**注意 MEMORY.md 中"Git 代理已配置为 SOCKS5"是错误的**，10808 是 HTTP 代理。
- 风险提示：58 个"超时"多为国际/港台源及部分上海移动源，可能只是 WSL 检测网络连不上，在用户电视网络可能可用（如河北卫视、星空卫视等）。已向用户提示并询问是否仅删 HTTP错误类、或重新拉取 sub.m3u 本地签名补回。
- 本地代理 sub.m3u 端点 192.168.8.188:50003/sub.m3u 可达（302），但 play/index.m3u8?sign= 的签名会过期，过期后该 URL 会超时被判死。
