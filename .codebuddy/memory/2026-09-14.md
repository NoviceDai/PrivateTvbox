# 2026-09-14 工作记录

## TVBox 配置 sites 有效性测试脚本
- 目标文件：`TV-BOX/纯福利/testok.json`。脚本落盘：`TV-BOX/纯福利/check_sites.py`（完整结果：`check_sites_result.txt`）。
- TVBox site `api` 三类判定：
  - **A 直连 http-api**（type 1/0）：探测 `{api}?ac=detail&t=1&pg=1`，要求 HTTP200+JSON(list/code)。
  - **B jar 爬虫 csp_*/带 jar**：`ext` 可能是字符串路径，也可能是**内联 dict**；从 ext(json 文件或内联 dict)里提取真实站点地址(分类url/url/搜索)探测。
  - **C 本地 .py 爬虫**：只能查脚本文件是否存在，无法 HTTP 测。
- 踩坑与修复：
  1. `ext` 为 dict 而非 str → 用 `urls_from_obj()` 提取 dict 内 URL。
  2. GitHub raw 等路径含中文 → urllib 抛 UnicodeEncodeError，需 `quote(url, safe=':/?#@&=+$,%')`。
  3. 代理 10808 做 TLS 拦截 → 必须 `ssl._create_default_https_context = ssl._create_unverified_context`，否则大量 CERTIFICATE_VERIFY_FAILED 误判。
  4. stdout 需 `reconfigure(encoding='utf-8')` 否则 emoji URL 打印崩。
  5. 代理偶发 TLS 中断 → fetch 加 1 次重试。
- 结果（testok.json，259 项）：**147 OK / 88 失效异常 / 24 仅文件检查**。
  - 其中 63 个失败是 `SSL UNEXPECTED_EOF`：本机代理 10808 无法对这些主机建 TLS（curl 走同代理也 exit=35，0.03s 断），多为成人向主机被代理拦截，**不能断定站真挂**，需在真实电视网络复核。
  - 明确失效(~16 站)：真实 HTTP 500/502/404/403（如 ✨Aries 一二三区、魔法少女系列 500；👊麻豆/🔞Sexnguon/㊙️麦田 502；㊙️PandaAV/🍁辣味 404；㊙️路漫漫/花都影视 403）+ 3 个 MISSING 的 .py 脚本(Xhamster.py/数逼毛/推特APP.py)。
  - 5 个 NO-EXT(jar 无 ext 字段)：无法验证，存疑。
- 注：本会话原本只有只读工具，后工具集恢复含 write/execute，故能落盘并运行。

## 按"明确失效才删"修剪 testok.json
- 用户要求：明确失效的删，不确定的保留。写了 `prune_dead.py`（逐站聚合探测结果决策）。
- **关键环境陷阱**：本 WSL 代理 10808 对连不上的主机，既报 `SSL UNEXPECTED_EOF` 也报 `HTTP 502`（代理自身 Bad Gateway）。因此 **HTTP 4xx/5xx 无法区分"源真死"还是"代理连不上"**，不能据此判定明确失效。
- `ghfast.top` 是 GitHub 镜像，多次运行间 **200↔502↔FAIL 跳变**（抽风）。验证：其底层真实 `raw.githubusercontent.com/...` 直连返回 200 → 源活着。故 `🔞...` 等 10 个镜像站点是**误删候选**，必须保留。
- **最终只删 3 个无歧义失效**：脚本文件缺失的 `.py` 爬虫（`Xhamster.py`→`./plugin/adult/Xhamster.py`、`数逼毛`→`4k.py`、`推特APP.py`→`推特APP.py`）。testok.json **165→162**，顶层结构完整。
- 候选"可能死"但环境无法确证（保留）：👊麻豆/㊙️麦田/🔞Sexnguon(502)、魔法少女1/2(500)、花都影视(403)、🍁辣味视频(404) — 这 7 个是直连主机返回错误（非镜像），倾向真死但需真实网络复核。
- 备份：`testok.json.bak_prune`（165 全量）。
- 结论：在受代理限制的环境下，唯一可无歧义判死的信号是"本地脚本文件 MISSING"；其余一律按不确定保留。

## 合并 origin.json → testok.json（有效站点去重加入）
- `origin.json` 与 `testok.json` 同在 `TV-BOX/纯福利/`。
- **origin.json 是 JSONC（含 `//` 与 `/* */` 注释），标准 `json.load` 报错**；写了 `merge_origin.py`，自带 JSONC 解析器（状态机去注释，忽略字符串内 `https://` 的 `//`）。
- 去重判定（与已有 testok 站点）：`key` 完全一致 / `name` 完全一致 / `api` 为 http 且完全一致 → 视为重复跳过（不重复添加）。注意 csp/jar 的 `api=csp_XBPQ` 是共享值，故未纳入 api 去重，避免误判 csp 站重复。
- 有效性沿用 `prune_dead` 的 `decide()`：**明确失效才不添加**（本地 .py MISSING / 全部真实 HTTP 4xx5xx）；EOF/FAIL/OK/NOEXT/NOURL/EXISTS 一律视为可加（保留不确定，与本项目一贯原则一致）。
- 结果（origin 62 站 / testok 原 162）：**3 重复跳过、8 明确失效跳过（均为真实 HTTP 502/404：台湾传媒②③④⑤⑥⑦、精东资源、富二代资源 404、AIvin 502）、51 添加（25 个确认 200 + 26 个代理 EOF/FAIL 不确定）**。
- 合并后 testok.json **162→213**，已自动备份 `testok.json.bak_merge_20260914130949`。
- 工具：`merge_origin.py` 支持 `--apply` 实际写回，默认 dry-run 打印计划。
